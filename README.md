# Joy Ripples Resort

Responsive hospitality website with the approved forest-green, copper and cream design.

## Preview locally

Run `python3 -m http.server 8000 --directory dist`, then open http://localhost:8000.

## Deploy

Publish `dist/` as a static website. No build or dependencies are required.

## Content

Includes dining, accommodation, catering, venue hire, team building, photo filters and gallery. Enquiry drafts are stored on the visitor’s device and are not sent to the hotel. The forest hero and room image are illustrative; other resort photographs were supplied by the client.
